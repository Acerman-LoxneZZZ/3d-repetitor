# Система движения

Документ описывает фактическую реализацию по исходникам. «Реализовано» означает наличие механики в коде, а не подтверждение плавности в браузере. При первоначальной реализации Chrome блокировался средой. После смены прав 24 октября выполнены 110 настоящих браузерных проверок изменённых разделов на шести ширинах; подробности в docs/updates-2026-10-24.md. Остальные сцены не объявляются покадрово проверенными. Измерения FPS и показатели Lighthouse не заявляются.

## Общие правила

- Сложные сцены используют локальные `assets/vendor/gsap.min.js` и `ScrollTrigger.min.js`; зависимость от CDN отсутствует.
- Контроллер: `src/motion.js`, `initMotion()`. Системная настройка `prefers-reduced-motion` читается при запуске и отслеживается через событие `change`.
- Ручная пауза сохраняется в `localStorage` (`math-motion-paused`). Кнопка в футере меняет текст и `aria-pressed`; при системном reduce она объясняет источник настройки.
- Основной breakpoint: 768 px. Pointer-эффекты разрешены только при `(hover: hover) and (pointer: fine)` и включённом движении.
- CSS-ритм: micro `.24s`, standard `.5s`, scene `.95s`, easing `cubic-bezier(.22,1,.36,1)`. GSAP: `power3.out` для локальных появлений, `power4.inOut` для занавесов и меню, `none` для связи с прокруткой.
- Позиции ScrollTrigger обновляются после загрузки шрифта, изображений и изменения FAQ. `gsap.matchMedia()` возвращает очистку локальных pointer-обработчиков, IntersectionObserver и visibilitychange при смене breakpoint. При `pagehide` декоративный контекст снимается; при возвращении через bfcache пересоздаётся.
- Зацикленные сцены возобновляются после возвращения вкладки только при видимом элементе. Смена системной настройки/ручной паузы сбрасывает курсорное превью и магнитные слои; ручная пауза также скрывает уже открытые декоративные контейнеры CSS-правилом.
- Красная тема использует `--page:#d3232a` после проверки контраста; `#e1282c` из мастер-промпта остаётся исходным ориентиром. Герой красной темы — `#c22127`.
- Контент присутствует в HTML до инициализации эффектов. Скрытие вступления по умолчанию предотвращает блокировку страницы без JS/GSAP.

## Функциональность без декоративного движения

Навигационные ссылки, FAQ, учебные этапы и проверка ответов не требуют окончания tween. При отсутствии JS остаются основной текст, семантические заголовки, демонстрационные материалы и статичное объяснение квадратного уравнения на странице подробностей. Персональные контактные ссылки появятся после заполнения конфигурации; фиктивная отправка отсутствует.

Звука, видео, шейдеров и стороннего smooth-scroll контроллера нет. Прокрутка нативная, CSS smooth отключается при ручной паузе и системном reduce.

## Границы проверки

Этот перечень составлен чтением кода, а не наблюдением в работающем браузере. Проверка быстрых повторных действий, bfcache, смены размеров, реального touch, 200% текста и реального endpoint требует доступного браузера/данных владельца. Неизмеренные тайминги референсов не выдаются за совпадение с оригиналом; происхождение решений описано в `reference-audit.md`.

После исправлений выполнено одно подтверждающее чтение изменённых контроллеров, CSS-состояний и подключений страницы разбора. Node-проверка подтвердила, что телефон из одних дефисов отклоняется, корректный номер принимается, а некорректная прямая телефонная ссылка не создаётся. Это проверка логики, а не визуальная верификация анимации.

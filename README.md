# Персональный сайт репетитора по математике

Реализация MASTER_PROMPT_TUTOR.md: адаптивный персональный сайт с оригинальным 3D-портретом, двумя темами, меню с изогнутым краем, магнитными CTA, математическими превью и содержательными учебными разборами.

Сейчас включён **предпросмотр**: сведения о преподавателе и канал связи ещё не предоставлены. Отзывы отсутствуют, контакты не выдуманы, отправка без endpoint скрыта.

## Запуск

Нужен Node.js 20+. Установка npm-зависимостей не требуется: шрифт, GSAP, ScrollTrigger, изображения и библиотека для рендера/проверок сохранены локально.

```bash
npm run dev
```

Откройте http://127.0.0.1:4173. Другой порт: `npm run dev -- --port 4174`.

```bash
npm run check
npm run build
npm run preview
```

`dist/` — готовая статическая сборка. `npm run preview` обслуживает её на том же порту 4173. HTML с ES-модулями нужно открывать через сервер, а не двойным щелчком по файлу. Ранее sandbox запрещал сервер; после изменения прав локальный просмотр доступен. В этой сессии сайт работает на http://127.0.0.1:4188/ (`npm run dev -- --port 4188`), поскольку 4173 занят другим проектом.

## Данные преподавателя

Редактируйте **src/config.js**. Здесь находятся имя, роль, подтверждённая аудитория, формат, город, опыт, образование, длительность, стоимость, портрет, контакты, услуги, подход и флаги предпросмотра.

Неизвестные значения остаются `null`. В режиме предпросмотра видны заменяемые поля. Для услуги задайте `confirmed: true` после согласования. При `preview: false` неподтверждённые услуги и условия скрываются в работающем интерфейсе. Предложенный процесс тоже скрывается, пока не установлен `processConfirmed: true`.

Путь `owner.photo` позволяет заменить иллюстрацию настоящим фото. Иллюстрация не выдаётся за фотографию владельца. Изменение имени автоматически подстраивает размер смыслового заголовка после загрузки шрифта.

Конфигурация подставляется и в HTML без JavaScript: локальный сервер и статическая сборка используют тот же `src/content.js`, что и браузер. Ручная замена полей в HTML не требуется. После изменения конфигурации перезапустите dev-сервер или заново выполните сборку. Публикация в рамках этой работы не выполнялась, как требует мастер-промпт.

## Контакт и отправка

`contact.telegram` — username без `@`; `email` и `phone` — реальные контакты. Они превращаются в обычные ссылки. Некорректные значения не становятся ссылками.

Если `contact.endpoint` отсутствует, форма скрыта. На текущем сайте честно указано, что контакты и отправка ещё не подключены. Для включения формы укажите свой серверный HTTP(S) endpoint; секреты отправки должны находиться на сервере.

Запрос: `POST`, `Content-Type: application/json`:

```json
{
  "name": "Имя посетителя",
  "method": "telegram",
  "contact": "@username",
  "message": "Необязательное описание задачи",
  "direction": ""
}
```

Успех допускается только при HTTP 2xx и JSON **`{"success":true}`** после подтверждённого приёма обращения вашим сервером. Ошибка/таймаут сохраняют введённые данные. Есть проверка полей, блокировка повторной отправки и live-region. `privacyUrl` заполняется ссылкой на предоставленную политику; вымышленное согласие не добавляется. Реальный сервер и доставка в этой сессии не проверялись.

## Страницы и материалы

- `/` — знакомство, направления, интерактивный разбор, процесс, материалы, условия, FAQ и контакты.
- `/lesson.html?topic=quadratic` — x² − 5x + 6 = 0, точный график и практика x² − 7x + 12 = 0.
- `/lesson.html?topic=linear` — 2x + 3 = 11, объяснение равенства и практика.
- `/lesson.html?topic=geometry` — треугольник 3–4–5 и практика по теореме Пифагора.

Все задачи авторские демонстрационные. Они не обозначены официальными экзаменационными заданиями. Без JS доступен полноценный статичный квадратный разбор, раскрываемое решение и основной контент главной. Выбор двух дополнительных статей по query-параметру требует JS.

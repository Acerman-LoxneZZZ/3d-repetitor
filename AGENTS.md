# Project instructions

Работайте по `MASTER_PROMPT_TUTOR.md`: он задаёт продукт, референсы, структуру и каталог M01–M24. `PRODUCT.md`, `DESIGN.md`, `reference-audit.md`, `motion-spec.md` сохраняют контекст реализации.

Для frontend-задач прочитайте локально установленный `.project-skills/frontend-design/SKILL.md` и применяйте его вместе с доступным Impeccable. Явное направление мастер-промпта имеет приоритет над выбором другого визуального мира. Не выдумывайте сведения владельца; редактируемые данные находятся в `src/config.js`.

Запуск: `npm run dev`. Проверки: `npm run check`. Сборка: `npm run build`. Зависимости уже локальны, установка npm не нужна. `tests/vendor/linkedom.mjs` — только Node DOM-проверки; их нельзя выдавать за визуальную проверку браузера.

Публикация требует отдельного указания владельца согласно разделу18 мастер-промпта. В этой среде Chrome и listen порта были запрещены sandbox: текущие ограничения записаны в `QA.md`, а не скрыты за утверждением о пройденной визуальной проверке.
